# Business Requirements Specification – CityEnergy

| ID | Requirement |
|----|-------------|
| BR-1 | Forecast hourly electricity load of a building cluster. |
| BR-2 | Provide prediction intervals with a stated 90 % coverage target. |
| BR-3 | Quantify degradation when weather or consumer behaviour changes (heatwave, cooling-response drift). |
| BR-4 | State that evidence is synthetic until metered data are available. |

Out of scope: real metering integration, demand-response control, any claim on real loads.
